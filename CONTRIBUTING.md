# Contributing to NexaFlow

We welcome contributions to NexaFlow! To ensure a smooth and collaborative development process, please follow these guidelines.

## How to Contribute

1.  **Fork the repository:** Start by forking the NexaFlow repository to your GitHub account.
2.  **Clone your fork:** Clone your forked repository to your local machine.
    ```bash
    git clone https://github.com/YOUR_USERNAME/NexaFlow.git
    ```
3.  **Create a new branch:** Create a new branch for your feature or bug fix. Use a descriptive name (e.g., `feature/add-time-trigger`, `bugfix/dashboard-crash`).
    ```bash
    git checkout -b feature/your-feature-name
    ```
4.  **Make your changes:** Implement your feature or fix the bug. Ensure your code adheres to the project's coding style and best practices.
5.  **Test your changes:** Write and run tests to ensure your changes work as expected and don't introduce regressions.
6.  **Commit your changes:** Write clear and concise commit messages.
    ```bash
    git commit -m "feat: Add new time-based trigger"
    ```
7.  **Push to your fork:** Push your local branch to your forked repository on GitHub.
    ```bash
    git push origin feature/your-feature-name
    ```
8.  **Create a Pull Request:** Open a pull request from your forked repository to the `main` branch of the original NexaFlow repository. Provide a detailed description of your changes.

## Code Style

-   Follow Kotlin coding conventions.
-   Adhere to the Clean Architecture principles used in the project.
-   Use Jetpack Compose and Material 3 guidelines for UI development.

## Reporting Bugs

If you find a bug, please open an issue on GitHub with a clear description, steps to reproduce, and expected behavior.

## Feature Requests

For new feature ideas, please open an issue to discuss them before starting implementation.

Thank you for contributing to NexaFlow!
